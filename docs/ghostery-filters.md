# Ad and tracker filter snapshot

`Block ads & trackers` uses `@ghostery/adblocker` 2.20.3 (MPL-2.0) for network request matching. The Playwright adapter is deliberately unused: its page route could take priority over the existing context route. The security route checks private workflow origin isolation first, then Ghostery rules, and the pinned-IP proxy still validates every allowed connection and redirect. Service workers and WebSockets remain blocked.

The image includes `server/filters/ads-trackers.bin`, a network-only snapshot compiled from Ghostery's EasyList and EasyPrivacy assets at upstream commit `6f0610bf5eec1f31c4975ce0e707cdf47023e5b5`. `server/filters/manifest.json` records each source URL, SHA-256 checksum, snapshot checksum and size. The source lists identify their licence at <https://easylist.to/pages/licence.html>; their headers report EasyList commit `436bb3af052fc0d94dbeb063ec309d068e3df0db` and EasyPrivacy commit `2ca3e18d690fa9be5e816ddc9c8293a03722dc0c`.

To update, review a new Ghostery asset commit and its upstream list headers/licence, replace the pinned commit and source SHA-256 values in `server/tools/update-ghostery-filters.mjs`, then run `node tools/update-ghostery-filters.mjs` from `server/` in a controlled development or CI environment. The command verifies both downloads before replacing the snapshot. Review the manifest and blocking/security tests in the same PR. A proxy-managed environment may require Node's `--use-env-proxy` flag. Normal captures, Preview and container startup make no filter download.

The runtime loads one shared immutable engine after checking the snapshot size and SHA-256. A missing or corrupt snapshot fails monitors with blocking enabled using `adblock_unavailable`; it does not fall back to unfiltered capture or update their baselines. Monitors with blocking disabled keep their previous network behavior. This release applies network filtering only. Cosmetic CSS, scriptlets, redirects and response rewriting are not injected into the page, preserving screenshot and DOM selection consistency.
